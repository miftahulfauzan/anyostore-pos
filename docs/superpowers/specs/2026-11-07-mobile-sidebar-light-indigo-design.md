# Mobile Sidebar Light Indigo Design

## Intent

Redesign the Android drawer sidebar using the selected Light Indigo concept while preserving the existing navigation and role behavior.

## Goals

- Use a light, airy drawer surface with Anyostore denim accents.
- Make group headings, active state, icons, dividers, profile, and logout visually consistent.
- Preserve current labels, order, role filtering, expansion state, callbacks, and routes.
- Keep the sidebar readable in both light and dark app themes.

## Non-goals

- No navigation or information-architecture changes.
- No new menu items, settings, gestures, or drawer behavior.
- No changes to page content outside the drawer.

## Visual decisions

- Light drawer background: near-white `#FBFCFF`.
- Soft indigo icon surfaces: `#E8F1FC`.
- Selected row: `#DCEBFC` with denim text and icon.
- Group headings: compact muted uppercase-style treatment with a thin divider line.
- Rows: icon circle, label, and existing trailing chevron; no large group cards.
- Drawer: same width, with a subtle right-side radius.
- Dark theme keeps the same structure and uses existing dark tokens for contrast.
