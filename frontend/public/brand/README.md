# Logo marketplace

Letakkan file logo di folder ini, lalu tautan di kode akan memakainya:

- `shopee.png` (disarankan 256x256, latar transparan atau oranye)
- `tiktok.png` (disarankan 256x256, latar transparan atau hitam)

Selama file belum ada, halaman memakai mark SVG bawaan
(`frontend/app/lib/brand-icons.js`) supaya tampilan tidak rusak.
